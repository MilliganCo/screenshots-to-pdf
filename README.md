# Screenshots to PDF

## О проекте

`Screenshots to PDF` — утилита для сборки длинного PDF из набора скриншотов или изображений. Проект ориентирован на полуавтоматическую обработку графики: обрезка по минимальной ширине, вертикальная или двухколоночная склейка и разбиение слишком длинных страниц.

## Что делает скрипт

- принимает набор изображений;
- нормализует ширину и обрезает кадры;
- умеет собирать длинную вертикальную страницу;
- поддерживает двухколоночный режим;
- разбивает слишком высокое полотно на несколько PDF-страниц;
- рассчитан на использование как скрипт или как собранный `.exe`.

## Стек и структура

- Python
- `Pillow`
- основные файлы: `merge_screenshots_to_pdf.py`, `merge_screenshots_to_pdf_v1.py`, `build_exe.bat`

## Запуск

```bash
python merge_screenshots_to_pdf.py
```

## Статус

Готовая прикладная утилита. Проект выглядит как рабочий инструмент для подготовки длинных визуальных документов из скриншотов.
